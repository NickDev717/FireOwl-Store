# Internacionalização (i18n) - Fire Owl Collectibles

O site suporta **3 idiomas**: Português (BR), English (US) e Español (ES).

## Como funciona

- O arquivo `translations.js` contém todos os textos traduzidos.
- O idioma é detectado automaticamente pelo navegador e pode ser alterado pelo seletor no canto superior direito da navbar.
- A escolha do usuário é salva em `localStorage` e mantida entre sessões.

## Uso

- Para adicionar uma nova tradução, edite o objeto `translations` em `translations.js`.
- No HTML, use o atributo `data-i18n="caminho.chave"` para textos.
- Para placeholders, use `data-i18n-placeholder`.
- Para aria-labels, use `data-i18n-aria`.

## Estrutura das chaves

As chaves são organizadas por seção:  
`navbar`, `hero`, `filtros`, `catalogo`, `sobre`, `footer`, `player`, `modal`, `pedidos`, `idiomas`.

Exemplo: `hero.titulo` → "Colecionáveis de Elite" (pt-BR).

## Manutenção

Para adicionar um novo idioma:
1. Adicione uma nova chave no objeto `translations` em `translations.js`.
2. Inclua a opção no seletor em `index.html` (dentro de `.lang-menu`).
3. Atualize o mapeamento em `updatePageLanguage()` em `script.js` se necessário.

## Notas

- O sistema é leve, sem dependências externas.
- As traduções são aplicadas dinamicamente, sem recarregar a página.
- Fallback para o texto original caso a chave não exista.
