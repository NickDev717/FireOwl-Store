# Fire Owl Collectibles - Site de Action Figures Premium

Site especializado em action figures e coletáveis premium com design luxuoso inspirado na identidade visual Fire Owl.

## 🦅 Características

- **Design Premium**: Tema dourado/preto com estética de luxo
- **Totalmente Responsivo**: Adapta-se a todos os dispositivos
- **Performance Otimizada**: Sem travamentos ou micro-stutterings
- **Busca Avançada**: Filtros por marca, franquia e faixa de preço
- **Sistema de Comentários**: Integração com EmailJS e localStorage
- **Player de Música**: Mini player flutuante com controles completos
- **Métricas Automáticas**: Cálculo automático de estatísticas do JSON
